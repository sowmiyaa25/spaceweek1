# SPACE WEEK 2026 — THE JOURNEY BEYOND (Day 1 activity)

A single space-mission activity for students. Plain HTML, CSS and JavaScript. Nothing is saved or tracked: each visit starts a fresh mission.

## Files

| File | What it does |
|------|--------------|
| `index.html` | Page structure: background, landing screen, mission screen. |
| `style.css`  | All looks. Colours and fonts are at the top under `:root`. |
| `missions.js`| **All mission text, answers, XP and the "what you learned" recap.** |
| `script.js`  | The game engine (plays the steps in `missions.js`). |
| `assets/`    | Images, icons, sounds (optional, empty for now). |

## Run it

Double-click `index.html`.

## Change things

- Story, questions, correct answers, XP, recap: `missions.js`
- Colours: `:root` at the top of `style.css`

## Publish with GitHub Pages

1. Create a free account at github.com.
2. Click **New repository**, name it `space-week-2026`, set **Public**, click **Create repository**.
3. Click **uploading an existing file**. Drag in `index.html`, `style.css`, `script.js`, `missions.js`, `README.md` and the `assets` folder. Click **Commit changes**.
4. Open **Settings → Pages**.
5. Under **Branch** choose `main` and `/ (root)`.
6. Click **Save**.
7. Wait 1–2 minutes and refresh. Your public link appears at the top, like `https://YOURNAME.github.io/space-week-2026/`.
8. Open it on your phone and play through the mission.
9. Make a QR code with any free QR generator using that public link.
10. Test the QR with two or three phones before printing. It must contain the `github.io` link, never a `localhost` or GitHub edit link.
